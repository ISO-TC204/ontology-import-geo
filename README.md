# ontology-import-geo

Import of the GeoSPARQL ontology for ITS visualization. Available at [https://isotc204.org/ontology-import-geo](https://isotc204.org/ontology-import-geo).

NOTE: The ontology has been tweaked to allow it to properly generate the documentation for this site. For example, the ending of the ontology IRI was changed from a `#` to a `/` to allow hyperlinks to work correctly.
